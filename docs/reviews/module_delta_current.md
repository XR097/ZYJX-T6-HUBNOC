# HUB / MAE_CRU 当前结论（V1.8）

## 先记住六件事

1. **唯一正式基线是 `docs/specs/` 的 V1.8**；本目录和 `hub_spec/` 只做追踪、验证和审查。
2. **HUB = HUB_NOC + HUB_IDN**：HUB_NOC 连接中央 L2 与四核，HUB_IDN 把 NI 的一路 32 B 按每字核集合分发；两者没有数据直连。
3. **HUB 只搬运**：不生成地址、不解析载荷、不做归约、不维护完成计数；H2C/C2H 的责任边界以正式篇为准。
4. **RHUB 已退役**：MAE_CRU 在 MAE 组内经 L2 读写完成归约、残差和读集并；结果回核另发 H2C 指令。
5. **变长对象按现行格式处理**：元数据项、E8M0、F 列表和码块先后写入；完成和应写量由发令方按正式协议计数。
6. **设计启动前仍有 blocker**：N-18、N-04 和 V18-01…V18-12，完整清单见[台账](open_issues_current.md)。
