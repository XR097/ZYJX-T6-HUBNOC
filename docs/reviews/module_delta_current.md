## 当前模块结论

- HUB 组为 **HUB_NOC + HUB_IDN**。HUB_NOC 连接中央 L2 与四核并转发命令网；HUB_IDN 将 NI 的一路 32 B 输入按每字核集合分发到四核。两篇之间没有数据连接，均不生成地址、不解析载荷、不判断搬运完成。
- H2C 每道只有 L2 一个源；C2H 每核只有集成输出端口→L2WP 一条路径。C2H 下游反压经发送 FIFO 的 `stall_tx` 门控 CCU。HUB 的通用链路块可插寄存器/skid，不另设专用多播存储。
- 正向为 `en/ready`；读返回为 `vld`；反向最终写入握手为 `valid`，没有 ready。**C2H 回程不带号，H2C/IDN 带 src**。同拍回程可包含不同 src，不得串源。最终完成由发令方计数，HUB 只转交。
- H2C 核掩码是单位参数，随每拍流水；IDN 核集合可逐字改变。分叉对尚未取目的拉高 en，en 不依赖 ready；所有目的可接收时必须支持每拍一字，不能用额外 ACCEPT_NEXT 状态引入空拍。
- 独立 RHUB 已退役。MAE_CRU 属 MAE，路径为 **各核 C2H→L2→NI 读口→CRU→NI-L2C→L2**，不直接连 HUB/HUB_IDN。报告收集、地址和写入计数归 MAE_ENG；结果交出归 CRU；依赖调度归 LIC。
- CRU 支持逐元素、FP32 标量、读集合并。逐元素输入为 FP16/BF16/MXFP6 g32/FP8，输出为 BF16/FP16/MXFP6 稠密或按列表压缩；数值按 §5.5 的 FP32 固定次序、末次 RNE/一次 QNT 量化参照逐位一致。
- 归约与残差加是两条指令；LIC 在第一条执行完成后下发第二条，Fusion-L3PU 可按块循环。残差输入可含紧凑 MXFP6、按 keep 展开且缺位补0；残差输出稠密。CRU 结果若送核 L1，另发经 H2C 的搬运。
- 变长对象按实际长度紧挨存放，token 长度表独立；先搬表再搬数据，搬完转发实际发出项数。压缩输出的长度表由 ENG 写完后再完成。L1/L2 负责跨字对齐，跨字计数冲突见 N-19。

依据：HUB_NOC §1–§10；HUB_IDN §2–§8；MAE_CRU §1–§7；MAE_ENG §4.2、§9.4、§10；协议 §3.3、§3.8、§4.3、§7.1。

## 旧结论处理

| 旧结论 | 当前处理 |
|---|---|
| HUB 透明传输、不生成地址、不判断完成 | 保留，扩展到 HUB_IDN；通用 skid 不等于另配专用存储 |
| H2C 为 L2/CRU 双源，C2H 可分流 CRU | 撤销；H2C 单源、C2H 单去向 |
| CRU 自带入口 FIFO、合并存储和地址到达表 | 撤销；L2 作输入缓冲，NI 读参与象限同址 |
| RHUB 被 MAE_CRU 取代 | 保留，但改为 L2↔L2 和多编码运算级 |
| CRU BF16 直出、归约回核再加残差 | 撤销；按指令编码，两指令在 L2 侧完成 |
| HUB 组只有 HUB_NOC，IDN 拆成 8 B | 撤销；独立 HUB_IDN，按整字分发 |
| 固定上限槽、VC/credit/flit/last/nw8/固定 RTT | 已退役；只作 Git 历史，不作为当前 RTL 接口 |
| CRU ERROR 状态、空掩码致命检查、全链路带号回程 | 撤销派生文档中的额外规定；遵循正文检查边界 |
