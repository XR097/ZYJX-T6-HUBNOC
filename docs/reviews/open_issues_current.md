# 当前问题台账（V1.8，2026-11-13）

本台账是设计和验证开始前的冻结清单。`docs/specs/` 是唯一正式需求基线；本页只登记跨篇冲突、外部输入和仍需验证的门槛，不把历史报告当作合同。

状态含义：`待审查` 需要规格负责人或外部接口负责人拍板；`待仿真` 机制已定、等待周期/功能回归；`待标定` 机制已定、等待容量/面积/时延/精度数据；`已关闭` 已有正文依据和检查结果。
