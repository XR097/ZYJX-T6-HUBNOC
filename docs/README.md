# L3PU 文档入口

`specs/` 是唯一的 V1.8 正式需求基线（2026-11-11）。旧的 2026-11-08 正文、重整报告、源稿快照、退役图件和生成缓存已从工作树移除，历史通过 Git 追溯。

| 目录 | 用途 |
|---|---|
| [specs/](specs/README.md) | V1.8 正式需求、引用配图、暂存设计输入和必要检查工具 |
| [hub_spec/](hub_spec/README.md) | 我们维护的需求追踪、合同、时序、接口矩阵、验证计划与术语表 |
| [reviews/](reviews/README.md) | 当前结论与待审查、待仿真、待标定事项 |

HUB 组由 `HUB_NOC` 和 `HUB_IDN` 构成：前者连接中央 L2 与四核，后者将 NI 的一路 32 B 输入按每字核集合分发到四核。独立 RHUB 已退役；其合并职责由 MAE 组内 `MAE_CRU` 经 L2 读写实现。设计与验证开始前的未决项统一登记在 [当前问题台账](reviews/open_issues_current.md)。

正文是依据，`hub_spec/` 和 `reviews/` 是派生分析。口宽/条数/方向以架构篇总表为准；协议与模块正文之间的残留冲突记录在当前台账，不能据此自行增加接口、错误状态或检查。
