# 新版模块文档包

这是 2026-11-03 起整理、2026-11-07 作为当前基线使用的模块文档包。HUB/RHUB 相关入口：

- `HUB_NOC.md`：透明 H2C/C2H/控制道合同。
- `MAE_CRU.md`：替代旧 R-hub 的 MAE 合并运算级。
- `DATA_TRANSFER_PROTOCOL.md`：当前核间写流、地址主和写入握手协议。
- `MAE_ENG.md`、`L1_SRAM.md`、`L2_SRAM.md`：地址生成、接收存储和最终写入语义。

`_build/` 是生成脚本、审计记录和预览中间物；`figs/` 是随当前稿引用的图件。构建中出现的旧方案、撤销记录和历史术语不构成当前合同，当前结论以正文章节为准。
