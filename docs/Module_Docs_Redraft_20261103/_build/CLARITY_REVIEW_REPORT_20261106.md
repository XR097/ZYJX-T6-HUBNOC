## 2 Agent 核出的设计空洞（已由协调者裁定，写进 `TP_RENAME_NOLAST_BRIEF_20261106.md` §3）

| # | 项 | 裁定 |
|---|---|---|
| 1 | PIN 的 B 响应按一个总写计数归属会误判（各象限 FIFO 写进 bank 的先后 ≠ 链路顺序） | 写计数按（入链路, 象限）维护，四象限到齐才回 B（V18-TP-43） |
| 2 | 长度转发与数据走两张时延无关的网，发出次序保证不了先到达 | 数据可先落地，长度转发只门控消费（V18-TP-44） |
| 3 | W / S 类一个存储字由一条 8 B 道送全需要 4 × 32 B 拆拍寄存器 | 放 NI_INT 读返回分路，结构性寄存器、不是入站缓冲 |
| 4 | 两源链路分配不同时交叉跟随谁 | 链路分配随单位走，单位边界切换 |
| 5 | 相邻命令能否重叠执行 | 允许，记录按请求分路 |
| 6 | PIN 尾字的时间界 | 在 AXI WLAST 拍交出 |
