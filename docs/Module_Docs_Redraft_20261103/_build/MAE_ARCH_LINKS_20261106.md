## 3 FIG-MAE_IDN-ARCH

内部结构（§3–§6）：两源合并 × 4（每道一个，单位级，§6）、多播缓冲 × 4（每道一个，每目的核一个读指针，§5）、交叉（道 → 核集合，单位边界切换，§4）、16 条输出链路（§3）。顺序按 §5 "该道把一拍放进自己的多播缓冲……各核按自己的 ready 取走"画作 合并 → 缓冲 → 交叉 / 扇出。
