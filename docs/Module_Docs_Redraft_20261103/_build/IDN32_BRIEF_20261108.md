## 1 裁定 V18-HUB-04（新规则，全文以此为准）

1. **IDN = 每核一条 32 B 的带地址的握手写流，全芯片 4 条；信号与 H2C 完全相同：en / ready / din 32 B / be 32 / addr 24 / `seg` 5 / `src`，反向写入握手（valid + `src`）。** 不再有"每核 4 条独立 8 B 链路"。
2. **MAE 的 IDN 出口交 HUB_IDN 一路 32 B（每拍一个存储字，带 addr / be / `src`），随每个存储字给一个 4 bit 核集合**（旁带，到核的链路上不带）。原"拆分需求 = 每字道号 + 每单位核集合 + 单位边界"撤：道号没有了，核集合改为随字，HUB_IDN 不再需要单位边界。
3. **HUB_IDN 只做一件事：按每拍的核集合把这一拍送到集合内每个核的 IDN 链路——接几核就是多播分叉点（一级通用链路块 + 每目的核 1 位已取，各核独立取走，V18-TP-53）。** 不拆拍、不缓存整字、没有拆拍寄存器、没有交叉开关、不算地址、不数单位。
4. **几核共享 M0 带宽 = MAE_ENG 的地址状态机把连续的存储字轮流排给各核**：字 0 → 核 0、字 1 → 核 1 …（或按编译链给的核次序）。原 {4} / {2, 2} / {2, 1, 1} / {1, 1, 1, 1} 四种"链路分配"改说成"各核轮到的字数比例"：单核吃满时 32 B/拍；四核均分时每核平均 8 B/拍，但每拍到达的是一个整字。总量仍由 M0 的 32 B/拍封顶。
5. **核侧 NWB 是与 LDP 相同的普通接收桥**：一条 32 B 链路、一条入口 FIFO、ready = FIFO 未满、按 `seg` / addr 进 W / S / A 类写口、写进 bank 时回写入握手、一个写计数交 CCU。**没有攒字寄存器、没有"按到达次序拼字"、没有"一个字的 4 拍同一字地址"。** IDN 仍只送整字对齐对象（be 全 1；紧密对象只经 NI 写口进 L2，再经 H2C 进核）——这条保留，只是不再是"因为攒字寄存器凑不满"，而是搬运指令的约定。
6. 撤回：V18-TP-30 的"每核 4 条独立 8 B 链路、各一个攒字寄存器"；V18-HUB-03 的"每道一个 32 B 拆拍寄存器、每字道号、4 拍同一字地址、NWB 按到达次序拼字"（HUB-03 中"MAE 只给一路 32 B、两源在 MAE 内择一"保留）；HUB_IDN 篇"交叉是否换号【设计者定】"；L1 篇"IDN 链路 0–3 各一个写计数"（改为 1 个）。
7. 为什么（写进各篇"为什么"时用）：V18-L1-09 之后一个 DDR 拍 = 一个整存储字、只属于一个核，8 B 道是 V1.7 "一拍交织 4 列"布局的残留；16 × 8 B 与 4 × 32 B 线数相同（每核 32 B）；一核只有一条链路，11-05 夜担心的"4 道同拍耦合"不存在；撤掉拆拍寄存器、攒字寄存器、4 拍同地址规则与交叉开关，每字时延 4 拍 → 1 拍；IDN 链路与 H2C 链路成为同一种口。用户 11-08 原话见 §0。

## 2 替换表（词级，正文与图脚本都适用）

| 改前 | 改后 |
|---|---|
| 每核 4 条（独立的）8 B 链路 / 4 条独立链路 / 16 条链路 | 每核一条 32 B 链路 / 全芯片 4 条 IDN 链路 |
| 4 道 × 8 B / 4 条 8 B 道 / 道 $i$ → 核 $i$ | 一路 32 B，按核集合分发 |
| 拆拍寄存器（HUB_IDN 的） | 删（HUB_IDN 没有存储） |
| 攒字寄存器（NWB 的） | 删（NWB 整字直写）；QNT、L2 攒字寄存器、NI_EXT 的 M1 拼字与本次无关，不改 |
| 一个字的 4 拍带同一个字地址 / 4 拍同地址 / 按到达次序拼字 / 四拍凑满整字即写 | 一个存储字一拍整字写入 |
| 道号 / 每字道号 | 删；核集合随字 |
| 链路分配 {4} / {2, 2} / {2, 1, 1} / {1, 1, 1, 1} | 各核轮到的字数比例（单核吃满 32 B/拍；四核均分平均每核 8 B/拍，每拍到达整字） |
| 拆分需求（每字道号、每单位核集合与单位边界） | 核集合（4 bit，随每个存储字） |
| 交叉开关 / 交叉是否换号 | 删；只剩按核集合的分叉点 |
| "一个存储字由同一条道送全" | 删，或改"一个存储字一拍送到" |
| NWB 每条链路一个写计数（IDN 链路 0–3） | NWB 一个写计数 |
| 整列发给属主核时"四条道都接属主核 / 四条链路合计 32 B/拍" | 属主核的链路每拍一个整字，32 B/拍 |
| C10 "16 条链路各 1 × (valid + src)/拍，每拍至多 16 个 valid" | 4 条链路各 1 × (valid + `src`)/拍，每拍至多 4 个 |
| C12 "拆分需求：道号随字、核集合与单位边界随单位" | 核集合随每个存储字（4 bit 旁带，随 D6 的数据走） |
