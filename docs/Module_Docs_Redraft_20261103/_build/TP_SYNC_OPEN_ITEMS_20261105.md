## 0 总的裁定

- 不照 NCC 字节协议；对齐单位 = 记录，每条记录补到 32 B（= 一个 bank 宽）；32 B 单位命名"存储字 / 字号"。
- 写侧：每类一个集合器，所有写者（含 H2C / IDN 落地）各一条 FIFO、按优先级分道；A 类 4 / 8 bank 可配；读侧 CCU 排、固定 1 拍。
- 变长对象 bump 分配；上限只给并发增长的 token 槽。

| 9 | barrier 落地信息、按份计数、到齐计数 | hub 的完成转 CRU；按份计数在 LIC；到齐计数作 MAE → CCU 短消息 |

| 12 | 三条上限规则 | 只用于并发增长的 token 槽与静态检查（TP-19）；顺序产出的对象 bump 分配、无上限 |
