# MAE 权重整形单元（MAE_WSU）需求

> Owner: WangYizhao｜2026-11-06｜正式稿第一版，待用户审阅。按用户 11-06 确认的目录（`../V17_3_MODULE_TOC_MAE_WSU_20261106.md`，W1–W3 已定）编写；依据 `Claude_Design_Spec/V1.7_3/Modules/MAE_NI_INT.md` 的 WSU 条款（NII-F-510…590、NII-R-170 / 180 / 210 / 220 / 280，冻结基线）、片上数据传输协议篇 `DATA_TRANSFER_PROTOCOL.md`（下称"协议篇"）、L1 正式稿、`Claude_Design_Spec/V1.8_DESIGN_REVISIONS.md`（V18-NII-03 及其 11-06 修订、V18-TP-27 / 36 / 37 / 38 / 41 / 42、V18-L1-09）。与 V1.7_3 冲突处以 V1.8 为准。

MAE_WSU 是 MAE 组五个单元之一，全芯片一个，也是 MAE 组里唯一的**变换类**单元。**它把前向形式存放的权重 $W$（$K \times M$，MXINT8 hi / lo 4 bit 平面 + E8M0 尺度，标准布局或列深度优先布局）整形成训练核消费的 $W^{\mathsf T}$ 列字块——32 个 16 B 列字加一个 32 B 旁带行，共 544 B——并算出每块的块尺度；输入可从 DDR（经 NI_INT 的读返回分路）或 L2（经 NI-L2C 返回车道）来，输出去 L1（经 MAE_IDN）或 L2（经 NI-L2C 写客户）。** 它是片上唯一改变权重字方向、做块内尺度计算的元件；只改位置与做精确的指数运算，不是量化点；只处理命令标为整形的那一份，原形那一份与其余数据不经过它。DDR 里只存前向形式的权重，反向不另存 $W^{\mathsf T}$（用户 11-06），所以没有片外出口。

## 1 组成与位置

### 1.1 位置

MAE 组 = MAE_ENG、NI_EXT、NI_INT、MAE_IDN、MAE_WSU（V18-NII-03 / 04）。MAE_WSU 的上游是 NI_INT（读返回分路给 DDR 原形、NI-L2C 返回车道给 L2 原形），下游是 MAE_IDN（去训练核 L1）与 NI_INT 的 NI-L2C 写客户（去 L2，供之后经 H2C 多播）。整形搬运由 MAE_ENG 的命令发起（ISA 影响 TP-ISA-8）。与 MAE 组外的连接经 MAE 组的对外口，口的划分见 MAE 集成篇（待写）。

把整形放在 MAE 组而不是各核，是因为同一份 DDR 读可以同时服务前向核（原形）与训练核（整形后），权重只读一次（D50 复用哲学）；独立成单元而不是藏在 NI_INT 里，是为了让它也能从 L2 取数、向 L2 输出——权重驻 L2 的位点不必再读 DDR，整好的 $W^{\mathsf T}$ 可以先存 L2 再多播，把约 427 拍的首块等待移出训练读的关键路径（用户 11-06）。

### 1.2 做什么、不做什么

| 做 | 不做（归谁） |
|---|---|
| 三种形态模式之一：拼接直通、转置写、原样（§4） | 不量化、不舍入：数字位只改位置，块尺度是精确的整数运算（§5） |
| 块尺度 $e_{\max}$、$\Delta_m$ 与旁带行 / 旁带表（§5） | 不生成地址：输入输出每拍 addr 由 MAE 的通道给出（V18-TP-27） |
| 先 hi 后 lo、尺度复用（§5.3） | 不缓冲整列、不判完成（写计数在接收方，V18-TP-37） |
| 进出口都是通用链路块实例（§6.4） | 不处理原形那一份、K / V、激活（它们不经 WSU） |

### 1.3 术语

- **行字**：16 B，同一个 $k$ 下 32 个输出通道 $m$ 的 4 bit 码；标准布局的 DDR 单元里一行 32 B = 4 个 8 B 半行字（各 16 个输出通道）。
- **列字**：16 B，同一个 $m$ 下 32 个连续 $k$ 的 4 bit 码；列深度优先布局按列字存放。
- **$W^{\mathsf T}$ 列字**：训练核消费形态的一个字——$k$ 固定、沿 32 个输出通道展开（即 $W^{\mathsf T}$ 的一行 $m$ 方向的 32 个码），16 B；叶序为自然的输出通道序。
- **$W^{\mathsf T}$ 列字块**（现称训练块）：一个（32 个输出通道的段, K 组）的 32 个 $W^{\mathsf T}$ 列字 + 1 个 32 B 旁带行 = 544 B；L1 篇按块分 2 拍读（§4、L1 篇 §7.9）。
- **K 组**：32 个连续 $k$；**子段**：转置写时一次攒齐再转置的 $k$ 范围，长 $L_{\text{WSU}}$，由命令给、不超过硬件硬限。
- **块尺度**：$e_{\max} = \max_m e_m$，$\Delta_m = e_{\max} - e_m$（4 bit）；**旁带行**：块最大值 1 B + 32 个 $\Delta_m$ 16 B + 标志，补到 32 B；**旁带表**：核级驻留侧取 W 的位点上按列块另出的一张表，每（32-$m$ 段, K 组）一项，每项一个 32 B 尺度行。

两种变换都在 MXU 与 DDR 共同依赖的码与尺度定义之内——只改位置，或做无损的指数运算——所以**输出必须与软件参照逐位一致，格式合同不放开**（§8）。

## 4 三种形态模式，只由来源布局码派生

**形态模式只由命令里的来源布局码派生，不按 dX 份额或切分轴分形态；训练核收到的只有 $W^{\mathsf T}$ 列字块一种形态**（GRAD-UNI，V1.6；现行保留）。

### 4.1 拼接直通：标准布局 → $W^{\mathsf T}$ 列字，地址级完成

一个 1 KB 标准布局单元 = 一个平面同一 K 组的 32 行（$k$），每行 32 B = 4 个 8 B 半行字（各 16 个输出通道在该 $k$ 下的码，对应 4 核各一份）；单元前置 64 B = 64 个 E8M0（4 × 16 个输出通道，挂 hi 平面；lo 单元无前置，复用 hi 的块尺度）。

**WSU 用前置的 E8M0 在数字字到达之前算出块尺度与旁带行；对训练核那一份的每个半行字，把同一核、同一 $k$ 下相邻两个列块的两个 8 B 半行字落进同一个 16 B $W^{\mathsf T}$ 列字的两半**，叶序为自然的输出通道序。这一步只是给出落地地址，不产生新字节；有前向核同读时，训练核那一份与前向核那一份是同一批字节、经 MAE_IDN 分别送到（§6.3）。块尺度流水时延【设计者定】（参考 ≤ 8 拍）；因为拼接不暂存，首块没有子段等待。

![FIG-MAE_WSU-SPLICE 同一 k 下相邻两个列块的半行字拼成一个 Wᵀ 列字](figs/FIG-MAE_WSU-SPLICE.svg)

图中取 $k = 5$ 的一行：列块 $2b$ 的单元里核 $c$ 的 8 B 半行字装输出通道 $m_0 \ldots m_{15}$，列块 $2b+1$ 的单元里核 $c$ 的半行字装 $m_{16} \ldots m_{31}$；两者落进训练核 L1 同一个 16 B $W^{\mathsf T}$ 列字的前半与后半，字内按输出通道序。图按每半字 4 个通道缩画，实际每半字 16 个通道、每字 32 个；脚本断言拼出的 32 个码与两个半字按序相同。

### 4.2 转置写：列深度优先布局 → $W^{\mathsf T}$ 列字，攒齐一个子段整块转置

列深度优先布局按列字存放（一个列字 = $m$ 固定、32 个连续 $k$），训练核要的是 $k$ 固定、沿 $m$ 的列字，两者相差一个 32 × 32 的半字节转置。**WSU 把一个列块（32 个输出通道）的一个子段攒齐后整块转置**：

$$W^{\mathsf T}_{m,\ 32s + j} = W_{32s + j,\ m},\qquad 0 \le j, m < 32,$$

$s$ 为子段内 K 组号；输出列字 $j$ 即 $k = 32s + j$ 固定、沿 32 个输出通道展开，各叶相对块最大值的指数差由旁带给出。

- **子段长 $L_{\text{WSU}}$ 是硬件硬限【设计者定】**（参考 512 个 $k$），实际值随命令给出、不超过硬限；$K_t$ 分块须是 $L_{\text{WSU}}$ 的整数倍（编译链）；暂存须覆盖硬限。
- **到达次序由 MAE 的读序给出**：核级驻留侧取 A 时为三层顺序（$m$ 组 → $K_t$ 分块 → 组内各列块的该 $K_t$ 段），一个列块在本 $K_t$ 分块内按长 $L_{\text{WSU}}$ 的子段连续到达；取 W 时为列块读序，同一 32 列在本列块的 $k_{\text{blk}}$ 个 $k$ 上连续到达，子段长取 $\min(k_{\text{blk}}, L_{\text{WSU}})$。
- **吞吐与首块时延**：每拍至多读出、转置一个 544 B 的块；首块要等一个子段攒齐——$L_{\text{WSU}} = 512$、只读 hi 时 32 列 × 512 个 $k$ × 4 bit = 8 KB，按参考工况 19.2 B/拍约 427 拍（推导值）。这段时延只在接收 $W^{\mathsf T}$ 的训练核一侧暴露，前向核那一份不等（§7）。
- 暂存的组织（skew 写入、去 skew、半字节转置布线）是参考实现，归设计者；参考规模约 22 KB 暂存、约 30 k 门。

**转置写必须保留**（用户 11-06）：up / gate 等按列深度优先存放的平面只有这条路能得到 $W^{\mathsf T}$ 形态。

![FIG-MAE_WSU-TRANSPOSE 4 × 4 缩小例：列深度优先的列字转成 Wᵀ 列字](figs/FIG-MAE_WSU-TRANSPOSE.svg)

图中输入是 4 个列字（$m = 0 \ldots 3$，每个装 $k = 0 \ldots 3$ 的码 $W_{k,m}$），攒齐后转成 4 个 $W^{\mathsf T}$ 列字（$k = 0 \ldots 3$，每个装 $m = 0 \ldots 3$ 的码）；实际一个子段是 32 列 × $L_{\text{WSU}}$ 个 $k$，每 32 个 $k$ 出一块。脚本断言输出字 $j$ 的第 $m$ 个码等于输入字 $m$ 的第 $j$ 个码。

### 4.3 原样：旁路

训练关闭、该平面不参与训练、LSC 副本、OPT 执行核不是前向核时经双写落两核 L1 的 LoRA 副本——都不经 WSU，按原样落位。

## 5 块尺度与旁带

### 5.1 块尺度：$e_{\max}$ 与 $\Delta_m$，整数运算无损

**对每块（32 个输出通道的段, K 组）的 32 个 E8M0 指数 $e_0 \ldots e_{31}$，WSU 现算块最大值 $e_{\max} = \max_m e_m$ 与 32 个叶的指数差 $\Delta_m = e_{\max} - e_m$（4 bit 字段）**；E8M0 的来源：标准布局取单元前置 64 个中属于本块 32 个输出通道的 32 个；列深度优先取该列块列尺度向量中该 K 组的 32 个。块内不置换、不分段；核内没有对应的块尺度引擎。$\Delta_m$ 超出 4 bit 字段时的表示与 EXP-FOLD 偏移基准的上限【设计者定】——要定的是饱和还是分级，约束是消费侧（MXU_AFU 的道级指数偏移）用同一规则还原。

这一步是无损的：$2^{e_m} = 2^{e_{\max}} \cdot 2^{-\Delta_m}$ 恒等成立，消费侧把 $\Delta_m$ 折进道级偏移后，数值与按原尺度计算逐位相同。

![FIG-MAE_WSU-SIDEBAND 4 个 E8M0 → 块最大值与 Δₘ，打成旁带行](figs/FIG-MAE_WSU-SIDEBAND.svg)

图中 4 个输出通道的 E8M0 指数 5、2、7、4 → $e_{\max} = 7$，$\Delta = (2, 5, 0, 3)$；旁带行的字节编排：块最大值 1 B、32 个 $\Delta_m$ 各 4 bit 共 16 B、其余保留，补到 32 B。实际每块 32 个通道。脚本断言 $2^{e_m} = 2^{e_{\max}} / 2^{\Delta_m}$ 对每个通道成立。

### 5.2 旁带行与旁带表

- **旁带行**只有一种格式：块最大值 E8M0 1 B + 32 个 $\Delta_m$ 各 4 bit 共 16 B + 标志，其余字节保留（位序与编码随 ISA 定）。**它作为该块的附带项（32 B/块）随块送出**，落训练核 S 类作该块的尺度行；L1 段读口分 2 拍读块时块最大值与 $\Delta_m$ 随 32 个列字读出，所有收方 pod 都从这里取，不另设旁带区。附带项约占训练核所收字节的 $32 / 544 \approx 6\%$。
- **旁带表**（核级驻留侧取 W 的训练位点）：$W^{\mathsf T}$ 列块驻 L1 块区、各 pod 按需挑 $k$ 时，按列读出的列字拼不出随块旁带行，所以 WSU 在定形列块时按列块另出一份旁带表，随列块落训练核 S 类的表区：每（32-$m$ 段, K 组）一项，每项一个 32 B 尺度行，内容与随块旁带行逐位相同；表的位置与长度由位点指令给，与列块双缓冲同份轮换；lo 复用 hi 的表项。消费侧一个 pass 至多 2 个 K 组，每条列道按列掩码表的 K 组位从两套旁带里二选一（MXU_AFU、CCU_RTR 篇）。

### 5.3 先 hi 后 lo，尺度复用

**训练读全码（反传读 lo）时，同一（列块, 子段）先处理 hi、再处理 lo；lo 平面不带尺度，lo 块使用的块最大值、$\Delta_m$ 与旁带行必须与同块 hi 逐位相同**（同一码 $c = 16h + \ell$ 的两个平面共用一组尺度），由 WSU 重发。缓存、重算还是从 L1 回读【设计者定】——要定的是 hi 的 32 个 E8M0（或算好的 $e_{\max}$、$\Delta_m$）在 lo 到达前放在哪，约束是容量覆盖一个（列块, 子段）、逐位一致。只读 hi 的反传不读、不处理 lo；lo 可按梯度掩码只读列表上的部分。

### 5.4 dH 的 S 列

LM Head 权重 $W$ 为 hidden × vocab、词表项是列；dH 要的是它的 $W^{\mathsf T}$ 方向。MAE 的 IGE 按（32 列块, 子段）两层展开 gather 来的 S 列（每列每子段一次读，$L_{\text{WSU}} = 512$ 时 256 B 数字；该列块的列尺度向量在首个子段前读入），WSU 对它做转置写，送描述符指定的 dH 执行核、落其块区，旁带行作该块的尺度行；S 列只有这一份，不投前向核。

### 6.1 两个输入源

| 源 | 经 | 数据 |
|---|---|---|
| DDR 原形 | NI_INT 读返回分路 | 标准布局或列深度优先布局的 hi / lo 平面与尺度，32 B/拍 |
| L2 原形 | NI_INT 的 NI-L2C 返回车道 | 同上；权重驻 L2 的位点不必再读 DDR（V18-NII-03） |

两源不同时用（一条命令一个源）。

### 6.2 两个输出宿

| 宿 | 经 | 数据 | 之后 |
|---|---|---|---|
| 训练核 L1 | MAE_IDN（4 道 × 8 B） | $W^{\mathsf T}$ 列字块流：32 个列字落 W 类块区、旁带行落 S 类、旁带表落 S 类表区 | 训练核按 GRAD-UNI 消费 |
| L2 | NI_INT 的 NI-L2C 写客户（32 B/拍） | 同上，落 L2 逻辑地址 | MAE 之后经 H2C 多播给需要的训练核 |

**输出每拍 addr 由 MAE 的 WSU 通道逐拍给出，WSU 按固定顺序出块（列字 $0 \ldots 31$、旁带行）、不算地址**（V18-TP-27）；dest 恒为存储。没有片外出口：DDR 只存前向形式的权重（用户 11-06）。

### 6.3 双目的：第二份载荷

命令含"同一次读的原形同时投前向核"时，原形那一份不经 WSU、直接由 NI_INT 交 MAE_IDN 送前向核；WSU 的输出是同一次 DDR 读在 MAE_IDN 上的**第二份字节**，送该 K 组的属主训练核。MAE_IDN 的道合计 32 B/拍，两份载荷之和超过时只降速（第二份比例 $\rho \le 2/3$、含旁带约 0.6 为参考值，归数据流篇）。没有前向核同读时（独立训练、只为训练读的平面、dH 的 S 列）只有 WSU 这一份。

### 6.4 通用链路块与停发

WSU 的两个入口、两个出口都是协议篇 §5.3.2 通用链路块的实例（en / ready / addr / be / din / dest；skid 深度与流水级数为例化参数【设计者定】）。**WSU 暂存满时对上游拉低 ready**，NI_INT 分路随之停住、经 NI_EXT 拉低 M0 的 RREADY（或 NI-L2C 返回车道停发读）；只降速、不丢数、不报错。下游（MAE_IDN、NI-L2C 写客户）拉低 ready 时 WSU 保持当前拍。

## 7 时序关系

1. **块尺度先于数字**：标准布局由单元前置的 64 B 尺度满足；列深度优先由 MAE 在每个列块的首个子段前读入该列块的列尺度行（同一次读在 NI_INT 同时交 WSU 与前向核：WSU 算块尺度，前向核把它作尺度行写 S 类）。
2. **旁带先于该块首字到达接收核**：旁带行作为块的附带项与块同送，接收核 NWB 先落尺度行。
3. **lo 晚于同块 hi**：复用的尺度已由 hi 算出 / 写入。
4. **原形那一份不等 WSU**：暂存时延只在接收 $W^{\mathsf T}$ 的训练核一侧暴露；前向核只在 $K_t$ 边界停放，分块内各子段的到达次序不影响前向累加。
5. 整形命令与参数在位点边界切换；模型级配置在调用开始采样。

## 8 不得破坏的合同

- **输出与软件参照逐位一致**：拼接直通不产生新字节；转置写只改位置；块尺度与旁带是无损整数运算。
- **输出字节只由来源布局码与命令决定，与接收核内 pod 分工无关**；每个权重元素只存一份、只送一份。
- **原形宿收到的数据与不经 WSU 时完全相同**。
- **hi / lo 两块的块最大值、$\Delta_m$ 与旁带行逐位相同**。
- 不改任何数据位以外的内容；不改 K / V、激活与其他不经 WSU 的数据。

## 9 计数与复位

不上报计数；不做错误检查；复位清命令队列、暂存、列尺度缓存与旁带缓存；缓存按（列块, 子段）用完即无效；没有跨调用驻留的状态。

## 10 要求值与验收

### 10.1 要求值

| 项 | 值 | 性质与依据 |
|---|---|---|
| 吞吐 | 每拍至多读出、转置一个 $W^{\mathsf T}$ 列字块（544 B）；输入 ≤ 32 B/拍、输出 ≤ 32 B/拍 | 要求值；一块经 MAE_IDN 送训练核需 $544 / 32 = 17$ 拍，WSU 不是瓶颈 |
| 转置写首块时延 | 等一个子段攒齐：$L_{\text{WSU}} = 512$、只读 hi 时 8 KB，19.2 B/拍约 427 拍 | 推导值（参考工况） |
| 拼接直通块尺度流水 | ≤ 8 拍 | 参考值【设计者定】 |
| 子段长硬限 $L_{\text{WSU}}$ | 【设计者定】（参考 512）；暂存覆盖硬限 | 要定的是硬限与暂存容量，约束是 $K_t$ 为其整数倍 |
| 暂存与门数 | 约 22 KB 暂存（随 $L_{\text{WSU}}$ 上限）、去错位约 30 k 门、旁带打包 5–10 k 门，NAND2 等效 | 建议值【设计者定】 |
| 旁带开销 | 32 B/块 ≈ 6% | 推导值 |

### 10.2 验收

| 项 | 方法 | 判据 |
|---|---|---|
| 三种形态 | 逐位比对 | 输出列字与旁带行、旁带表与软件参照逐位相同 |
| 原形不变 | 逐位比对 | 原形宿收到的字节与不经 WSU 时相同 |
| hi / lo | 逐位比对 | 两块旁带相同；lo 不重复计算尺度 |
| 双目的 | 周期仿真 | 两份字节各自正确；超 32 B/拍只降速 |
| 两源两宿 | 周期仿真 | DDR / L2 进、L1 / L2 出四种组合结果相同 |
| 时延无关 | 随机化流水级数与 ready | 逐位一致、不丢拍、不重复（协议篇 §5.3.2） |
| 暂存满 | 随机停发 | 对上游拉低 ready，不丢数 |

## 11 为什么

- **一次 DDR 读同时服务前向核与训练核**（D50，复用哲学）：权重只读一次，训练核的形态差异在 WSU 一处解决。
- **WSU 独立成功能模块、两源两宿**（用户 11-06："权重整形必然需要，但是我认为可以调整下它的位置……可以接受 DDR 来的数据，也可以接收从 L2 SRAM 来的数据"）：L2 进避免训练核再读 DDR，L2 出把首块等待移出关键路径。
- **没有片外出口**（用户 11-06："DDR 中理论上只有为前向准备的局部，反向不会再额外存一份权重"）。
- **转置写必须保留**（用户 11-06）。
- **方向只在 WSU 换一次、块尺度集中在 WSU**（现）：各核 L1 只按地址落位、段读口不旋转不转置，pod 按固定导线取字。
- **GRAD-UNI 训练核只收一种形态**（V1.6）。
- **地址归 MAE 通道、完成归写计数、进出口是通用链路块**（V18-TP-27 / 37 / 38）。
- **子段长硬限交设计者**（用户 11-02 第 12 项）。
- 本篇各项细节按"非 MXU 模块只要求符合协议篇且能实现"交设计者（V1.8 §3）。
- 被否方案各一句：KRU、NI-FORK、NI 内置 WSU、预整形存片外。
