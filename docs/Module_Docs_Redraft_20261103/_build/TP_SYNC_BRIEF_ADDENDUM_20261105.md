## 新增设计点 S14–S20

| # | 设计点 | 协议篇 |
|---|---|---|
| S14 | **存储字 / 字号**：32 B 单位不再叫"行"；地址 = [堆][类][字号]；"列字 / 行字"（16 B 布局字）不改。正文所有指 32 B 单位的"行 / 行号 / 整行 / 尾行 / 跨行"改为"存储字 / 字号 / 整字 / 尾字 / 跨字"；矩阵的行、token 行、尺度行、旁带行不改 | §2.1 |
| S15 | **口 = 道的集合**：RRAM 一个口由若干道组成，每道固定接一个 bank、各自独立的 en / wea / addr / din / dout / vld；32 B 口 1 道；A 类写集合口 4 道（A 类配成 8 bank 时 8 道）；权重 lane 读口 8 道、各道 addr 可不同深度 | §3.1 |
| S16 | **写侧集合器**：写堆每 bank 一个写口；所有写者（H2C 接收桥 LDP × 4、NWB、QNT、出口级、SEL / SMP / OPT …）各一条 32 B 入口 FIFO（落地来源用接收桥自己的 FIFO），集合器每拍为每道按优先级选"队头落在该 bank"的写者；优先级表每类一张随位点命令由 CCU 装，默认落地 > IDN > 核内；写者只看自己 FIFO 的 wr_stall；L1 内无仲裁。**A 类 4 / 8 bank 两种配置，道数随之，写者侧接口不变**。读侧：读堆无写者，4 个激活类读口可读任一 A 类 bank，撞 bank 由 CCU 排开，固定 1 拍无 busy。W 类集合口 = NWB 与 H2C 多播权重二选一 → 8 道；S 类 2 入 → 1 道。编译链约束：同一阶段并发写者总需求 ≤ 道数 × 32 B/拍（含落地流） | §3.2、§4、§11 |
| S17 | **核间反压**：接收桥 / NWB 的 TREADY = 入口 FIFO 未满（不再"恒高"）；NWB 攒字缓冲将满同样拉低 TREADY；IDN 链路带 TREADY。L2：每象限一个集合器（L2WP、NI 写 → 4 道），先后按搬运命令里的抢占优先级；L2 读口加 busy（L1 不加） | §3.3、§6.2 |
| S18 | **bump 分配**：变长对象源空间按实际长度动态分配，不预留；只有权重驻留下并发增长的 token 槽留上限（$k$ + 强制入选数；不封顶位点 = 全保留长度 2,648 B；参与词号列表 = 两组 TOPK 的 $k$ 之和）；编译期静态检查另做 | §7.3、§9.7 |
| S19 | **其余裁定**：TUSER 类位第 4 码 = CRU（AEB 部分和、跨核 OR 的位图直送 CRU，结果经 HUB-DN 回核）；核间小消息（K 切分判决、区块并集、档表）当 ③ 档走 C2H → L2 → H2C；重放流 / H2C 激活入口撤、一律先落 L1；发送命令直接送 CCU（L1 命令单元并入 CCU 命令队列），命令带源环长与抢占优先级，CCU 发读；RIFT 归 CCU（32 B 内）；hub 的完成转 CRU，LIC 操作 15 按份计数在 LIC，列表到齐计数作 MAE → CCU / VNU 短消息；NI 写 L2 / L2 写回 DDR 的完成由 NI 报；L2 错误经 hub 控制道；"配置未就绪"= 位点指令未装入 CCU 时有落地写；PIN 窗口 =（堆位, 象限, 起始字, 长度），"分区表"撤 | §5.2、§6.1、§7.4、§8.1、§10 |
| S20 | **L1 / L2 架构图改为 PPT 风格**（用户 11-05："这两个模块比较重要，需要更直观的说明"）：各一张 1920 × 1080，风格与 `_build/draw_tp_arch.py` 的四张一致（可复用其 `Fig` 类与自检）；现有 FIG-L1_SRAM-CONN / FIG-L2_SRAM-CONN 退役（函数加 `_retired_`，SVG 移 `figs/_retired_20261105/`）；各配一张"4 bank ↔ 8 bank 配置"小例（L1）/"两堆 4 + 4"小例（L2，已有可改） | — |
