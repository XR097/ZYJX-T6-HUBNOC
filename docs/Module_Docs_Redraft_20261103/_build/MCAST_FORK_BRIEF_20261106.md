## 1 新规则（正文按此写）

### 规则 F：多播分叉点（修订 V18-TP-29）

- **多播分叉点 = 一级通用链路块 + 每个子输出 1 位已取标志；分叉点不另配存储。** HUB 的 H2C 道、MAE_IDN 相同。
- 每拍规则：对掩码内、本拍尚未取走的子输出拉高 en；某子输出 ready = 1 即取走并置位已取位；掩码内已取位全部置位后才接收上游下一拍，同时清零；**en 只看已取位、不看 ready**（不做"几个 ready 相与再给 en"——那样 en 组合依赖 ready，等于把等齐同拍搬回来）；单播 = 掩码只有一位。
- **"各目的核独立取走、不要求同拍成交"保留。** 快慢核的差距由各分支链路块的 skid 与接收侧入口 FIFO（LDP / NWB）吸收；需要更大余量时加深接收侧入口 FIFO，不在分叉点加存储。
- 与旧写法的关系（只在"为什么"里一句）：旧的"发送侧共享缓冲 + 每目的核一个缓冲地址"是带 $D$ 拍存储的分叉点；$D = 1$ 时每核的缓冲地址退化成 1 位已取。撤掉的是另配的存储。
- H2C 道停发 L2 读：看**道首级链路块的将满阈值**（深度 − 在途读拍数），不再写"多播缓冲满 → 停发 L2 读"。
- 背压句：某核 LDP 满时，该核分支先由其 skid 接住；分支满后分叉点停收上游，其余核在已取走的拍之后也要等——**一核长时间堵住会经分叉点拖慢其余核，余量 = 该核分支 skid + 接收侧 FIFO**。
- 写入握手汇总处（HUB §7、MAE_IDN）原句"各核从共享缓冲取数快慢不同" → "各分支快慢不同"。
- 计数项"多播缓冲满拍数" → "分叉点等待拍数（掩码内有核未取走而停收上游的拍数）"。复位"清多播缓冲" → "清分叉点的在途拍与已取位"。

### 规则 A：HUB 与 MAE_IDN 可由后端调整（V18-TP-54）

不定拓扑、不画树 / 中继节点 / 星形；拓扑与分叉位置由后端按布局定。七条需求（协议篇 §5.3 写全文，HUB_NOC、MAE_IDN 各自引用并写本篇的落点）：

| 编号 | 需求 | 后端能调什么 |
|---|---|---|
| A1 | **功能与任何一段的级数无关**：任意两端点之间是一串通用链路块，各段级数是独立参数，可各不相同；改级数只改参数不改逻辑 | 每段插几级 |
| A2 | **每级满吞吐**：每级自身能每拍成交，插级只增时延不降吞吐；skid 只看本级，不随总级数加深 | 插级不掉速 |
| A3 | **多播分叉点可移动、可拆成多级**：每级按规则 F；分在一处还是逐级分结果相同；核掩码作旁带走到最后一个分叉点，到核的最后一段不带 | 分叉点位置与级数 |
| A4 | **任何逻辑不依赖同拍到达或固定相对时延**：同核 4 条 H2C 链路之间、IDN 4 条链路之间、正向与写入握手回程之间都不对齐 | 各线独立走 |
| A5 | **写入握手回程的级数与正向独立**；握手先到后到不影响计数 | 回程另走 |
| A6 | **与时延有关的门限是 RTL 头文件参数**（如道首停发 L2 读的将满阈值 = 深度 − 在途拍数），无运行期配置；后端改级数只改参数 | 改级数改参数 |
| A7 | **验收随机化**每段级数、分叉位置、ready 时序与回程时延；数据逐位一致、写入项数与握手计数相符 | — |

- HUB_NOC §3.3"链路上没有核号"改为"**到核的链路上没有核号**；分叉点之前的段带 4 bit 核掩码旁带（A3）"。协议篇 §5.1 / §5.2 信号表相应加一句（旁带只在分叉点之前）。
- MAE_IDN：交叉开关按核集合把道接到一个或几个核的链路上，接到几个核就是分叉；交叉开关与分叉点的先后、位置同样可调（引用 A3）；原"两源合并 → 多播缓冲 → 交叉，次序【设计者定】"改为"两源合并 → 交叉 / 分叉，次序与位置【设计者定】（A3）"。

## 3 MCAST 新图（两篇各一张，例子相同）

一条道 6 拍单位多播到核 0、核 2（掩码 0101）；每个分支是容量 2 的链路块（寄存器输出 + skid 1）；核 0 的入口一直 ready，核 2 的入口在拍 2、3 不 ready。逐拍画：上游送入分叉点的拍号、分叉点已取位（核 0 / 核 2）、两个分支的占用、两核入口取走的拍号。由脚本逐拍仿真得出，断言：两核各收 6 拍且顺序正确；分支占用 ≤ 2；**本例分叉点从不停收上游、核 0 不等核 2**；再算一行对照（核 2 停 4 拍）断言分叉点会停、核 0 被拖慢若干拍，图下一句说明"余量 = 分支 skid + 接收侧 FIFO"。仿真模型写清（每拍先算出口取走、再算分叉点送入，ready 用拍初状态），常量写进登记表。
