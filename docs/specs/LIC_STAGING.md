## 2 条目

### 2.1 来自 MAE_CRU

- **LIC-S-01** **归约与残差加两条指令的先后与分块循环**（来自 MAE_CRU 源 §2.3 / §4.2；MAE_ENG 源 §5.10 / §9.4 / §12；V18-CRU-08、V18-MAE-13、V18-DORG-10 (10)）：核间 K 切分的残差位点由两条 MAE 搬运指令完成——先归约（四象限同址份相加，带 bias 时四份相加之后加一次 bias，输出 BF16 写 L2），再残差加（归约结果 + L2 里的残差流，输出稠密残差格式写 L2）；**LIC 在归约指令的完成通知到达后才下发残差加指令**；分块流式（位点输出按 token 块或列块分批产出）时两条指令放在一个 Fusion-L3PU 段里，LIC 按块循环下发（每块先归约、再残差加），MAE_CRU 不要求循环与记块号（协议篇 §3.18、MAE_CRU 篇 §3.10；用户 11-08："先一条指令做归约，再一条指令做残差，不过可以有Fusion指令来监督循环执行（如果涉及到分块流式）"）。

### 2.2 来自 MAE_ENG

- **LIC-S-02** **完成通知的用途**（来自 MAE_ENG 源 §10.3；V18-MAE-13 / 26、V18-TP-22）：LIC 据 MAE 的完成通知（valid + 指令标号，每条指令一次）分发依赖它的后续指令、做位点屏障（各核位点完成事件 + MAE 完成通知）、判调用完成，并在结果记录写完之后先写好留给 M55 的 (c) 类寄存器、再经 CIF 的事件置位口置调用完成事件（第三轮，V18-CIF-02 / 05，CIF 篇 §2.7、§3.7；原"写 CIF 的调用完成状态寄存器"被取代）；同址先写后读、结果记录先落地再写完成状态都由 LIC 收到前一条的完成通知后再下发后一条表达。
- **LIC-S-03** **KV 编辑展开**（来自 MAE_ENG 源 §2.3 / §11；V18-MAE-07）：LIC 把 KV 编辑列表展开为带列表的搬运指令；KV 作废无数据动作，只改 KV 段表。
- **LIC-S-04** **Fusion 段按批流水**（来自 MAE_ENG 源 §5.10 / §9.4 / §12；V18-DORG-10 (10)）：LIC 的 Fusion 段里搬运指令与计算指令成对循环，先搬一批、算一批，算的同时搬下一批（核间 K 切分残差位点的两条指令按块循环见 LIC-S-01）。
- **LIC-S-05** **K hi 驻留区的释放**（来自 MAE_ENG 源 §5.4；V18-ATT-01）：驻留区在覆盖它的全部录取单位精算完之前不可覆写，释放由 LIC 按完成通知安排。
- **LIC-S-06** **LIC 按 MAE 给出的指令入口地址表写搬运指令：字地址与生效字**（来自 MAE_ENG 源 §2.2；MAE 集成篇源 §3.2 C1；V18-TP-76；分层清单 MAE_INTEGRATION D1，用户 11-11"认可"）：LIC 经命令网（PORT-24，64 bit + 每拍 addr）把搬运指令按 MAE 指令入口内的寄存器字地址逐拍写入；一条 MAE 指令占几个 64 bit 字、写到哪一字生效由 MAE 设计者给出，LIC 与 ISA 照此对接；MAE 能在执行当前指令时预存下一条，LIC 可连续下发多条；每条带 LIC 分配的指令标号，MAE 执行完经完成通知专用信号组（PORT-38，1 组 valid + 指令标号）回报一次。

### 2.5 来自第三轮同步（CIF 定稿之后）

- **LIC-S-09** **LIC 是 CIF 在 L3PU 一侧唯一的寄存器读写方**（来自 CIF 篇 §2.5 / §2.7、同步清单 CIF §二；V18-CIF-05；CIF 篇已从 CIF 一侧写出）：LIC 收 CIF 的启动脉冲与调用描述符指针（无握手，启动只在空闲时发出，LIC 必须能收）；经寄存器读口读 (b) 类寄存器，经寄存器写口写 (c) 类里由 LIC 负责的寄存器，经事件置位口置事件位（事件 0 = 调用完成）。别的模块与 M55 的往来都经 LIC：M55 给 CCU 的配置由 LIC 读出后经命令网写进 CCU；CCU 等模块要给 M55 看的信息由该模块设计者与 LIC 设计者对接怎样交到 LIC。
- **LIC-S-10** **收停止请求后停止取指与下发**（来自 CIF 篇 §2.6 / §3.5；V18-CIF-03 / 04）：LIC 是六个发令方之一；收到停止请求后停止取指令、停发指令与 GO，保持状态，在登记的拍数上界内回"已停住"；撤销后接着做，不丢、不重、任务精度不变（V18-CIF-10）。拍数上界【待标定】登记到 CIF 篇 §4.3。
- **LIC-S-11** **向 CIF 登记所需寄存器与共享内存格式**（来自 CIF 篇 §2.2.2 / §2.8.1 / §3.9、同步清单 CIF §二；V18-CIF-05 / 06）：LIC 设计者向 CIF 登记调用完成时留给 M55 的信息（(c) 类，例：调用号、接受长度）、PIN 相关寄存器（PIN 输入的位置与长度可由指令给，也可由 M55 经 CIF 的 PIN 相关寄存器给，LIC 知道取哪一份）、其他需要 M55 介入的事件；调用描述符的字段由 LIC 设计者定后登记到 CIF 篇 §2.8.1。调用种类归 LIC 篇。
