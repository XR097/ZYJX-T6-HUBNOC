## 2 条目

### 2.1 来自 MAE_INTEGRATION

- **CIF-S-01** 【已吸收，见 CIF 篇 §7.6（各模块的性能计数不是需求；要给 M55 看的计数按 §2.2.2 登记 (c) 类寄存器）；"CIF 不装 PIN 窗口表"一句 CIF 篇未写，现由 MAE_NI_EXT 篇写出（地址换算是 RTL 头文件常量，V18-NIE-03）】 **MAE 组性能计数经 CIF 的 Monitor 寄存器读出只是参考实现**（来自 MAE 集成篇源 §3.2 C8、§7.2；V18-MAE-26；分层清单 G13，用户 11-11"不需要进入需求文档"）：MAE 篇不把计数项与 C8（NI_EXT ↔ CIF 双向寄存器口）写成需求；CIF 篇若保留 Monitor 寄存器，读口形式与计数项由 CIF 与 MAE 设计者对接。CIF 不装 PIN 窗口表（地址换算是 RTL 头文件常量，V18-NIE-03）。

### 2.2 来自 VNU_SMP

- **CIF-S-02** 【已吸收，见 CIF 篇 §2.8.1 格式登记表"随机数的位级绑定"一行（参考绑定见 VNU_SMP 篇 §7.3）】 **随机数位级绑定的登记**（来自 VNU_SMP 源 §3.4；V18-SMP-04 / 06）：Philox-2x32-10（Random123 官方定义），种子与（调用号, 轮号, 编号, Batch 行号）怎样装进 key 与计数器、取哪个输出字、怎样变成 $[0, 1)$、随机数向量每项的格式，由 SMP 设计者定、登记为与 M55 共用的唯一定义；Batch 多序列下编号互不重复、可重放。参考绑定：key = 种子低 32 bit；计数器字 0 = 种子高 32 bit ⊕（调用号 ‖ 轮号），计数器字 1 = 编号；取输出字 0 为 $x$，$u = \lfloor x / 2^{8} \rfloor \cdot 2^{-24}$。
- **CIF-S-03** 【已吸收，见 CIF 篇 §2.8.1 格式登记表"条件概率的 2 B 编码"一行】 **条件概率 2 B 编码的登记**（来自 VNU_SMP 源 §6.1、§7.2；V18-SMP-04）：条件概率记录每项词号 3 B + 概率 2 B；2 B 编码由设计者定（参考 BF16），M55 建树时相乘、拒绝采样时作为 $q_D$ 读回，登记为与 M55 共用的唯一定义。
- **CIF-S-04** 【已吸收，见 CIF 篇 §2.8.1 格式登记表首行（定义在 VNU_SMP 篇 §3.8，监督信息见 VNU_SMP 篇 §3.9）】 **结果记录、树记录组、监督信息的格式**（来自 VNU_SMP 源 §3.3、§6.1、§6.3）：结果记录含接受路径、AL、首个被拒槽号与有效位、终止方式、输出 token（18 bit）、监督行集合连同每行的深度与首拒标志、执行状态，log-prob 等为可选字段、默认不含；树记录组 = 每节点树记录 4 B（词号 18 bit + 父槽号 7 bit + TAG 2 bit + VALID 1 bit）、父槽表（每槽 7 bit）、节点档表（节点数 8 bit + 每槽 2 bit TAG）、祖先掩码（32 × 32 bit 块、每块 128 B）、嵌入词号列表、占槽数与有效节点数；监督信息不设每行字节上限（V18-SMP-09）。字段布局由 CIF 与数据组织篇定。
