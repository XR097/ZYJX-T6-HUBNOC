# HUB / MAE_CRU 术语表

| 术语 | 含义 |
|---|---|
| H2C / C2H | 中央 L2 到核、核到中央 L2 的数据方向 |
| IDN | NI 侧 32 B 输入按每字核集合分发到四核的网络 |
| `en` / `ready` | 正向有效请求 / 下游可接收 |
| `vld` / `valid` | 读返回有效 / 写入完成握手；两者不同 |
| `addr` / `seg` | 段内字节地址 / 5 bit 段选（堆选 1 + 段掩码 4 独热） |
| `be` / `src` | 32 bit 字节使能 / 发令号或来源号 |
| 报告 | 发令方确认对象已写入目的 L2 的专用通知 |
| 待审查 | 合同冲突或外部字段未定，必须先拍板 |
| 待仿真 / 待标定 | 机制已定，等待功能证据或数值数据 |
| 已关闭 | 正式篇和验证证据已一致 |

正式定义见 `docs/specs/ONCHIP_DATAPATH_ARCH.md`、`DATA_TRANSFER_PROTOCOL.md` 和对应模块篇；本页不覆盖正式合同。
