# HUB_IDN 合同

## 1 边界与职责

HUB_IDN 是 HUB 组中独立于 HUB_NOC 的分发模块。它接收 MAE 的单路 32 B IDN 写流，把每个存储字按旁带的 4-bit 核集合复制到四条核 IDN 链路。HUB_IDN 只做透明传输、分叉和写入握手汇总，不生成地址、不重排字节、不做运算或完成判定。

MAE 内部先在 NI 读返回路径和 MAE_DSU 输出之间择一；HUB_IDN 看到的始终是一路输入。MAE_CRU 的结果写回 L2，不经过 HUB_IDN；需要送核时由另一条搬运指令经 HUB_NOC H2C 发送。

## 2 接口

| 接口 | 方向 | 内容 |
|---|---|---|
| MAE IDN 出口 → HUB_IDN | 入 | `en/ready`、`din[255:0]`、`be[31:0]`、`addr`、`seg`、`src`、每字 `core_set[3:0]` |
| HUB_IDN → 核 n NWB（4 条） | 出 | 每条 32 B：`en/ready`、`din`、`be`、`addr`、`seg`、`src` |
| 核 n NWB → HUB_IDN | 入 | 写入 L1 后的 `valid+src`，无 ready |
| HUB_IDN → MAE_ENG | 出 | 四路写入握手按 `src` 汇总，不丢、不重、不串源 |

`core_set` 与数据、地址和 `src` 同拍进入通用链路块，并随流水到最后一个分叉点；到核链路上不再带该旁带。IDN 只传整字，`be` 通常全 1；紧挨对象由 NI 写入 L2 后再经 H2C 发送。

## 3 分发和多播不变量

- `core_set[c]=1` 才能向核 c 发出该字；集合为空是非法请求。
- 每个目的核有独立 ready 和已取位；某核先成交不等待其他核。
- 集合内全部目的取走后，分叉点才接受上游下一拍；每级可有 skid，容量和级数由后端参数化。
- 同一链路保序，级数只增加延迟；地址、`seg`、`be`、`src` 与 `din` 始终对齐。
- 一个输入字最多复制四份，写入握手按实际目的核数返回；HUB_IDN 不计搬运完成。

## 4 带宽边界

输入固定为 M0 的 32 B/拍。单核可吃满 32 B/拍；多核共享由 MAE_ENG 按连续整字轮排，平均带宽等于该核收到的字数比例乘 32 B/拍。多播复制不增加输入带宽，但会按目的核数增加 L1 写入量。
