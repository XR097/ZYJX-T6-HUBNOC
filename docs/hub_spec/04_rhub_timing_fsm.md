# MAE_CRU 时序

## 输入与到齐

CRU 存储按 `addr` 建立到达计数。每项写入都记录来源 `src`；当到达份数等于搬运指令给出的应到份数时，该地址进入合并流水。不同地址可并行等待，不要求全组同拍到齐。

## 合并与输出

合并种类由指令给出：部分和、标量类合并或读集合并。部分和结果 BF16 直出。地址范围全部完成后，CRU 回报 MAE_ENG；MAE_ENG 带指令标号通知 LIC。输出进入 H2C MUX 时按源顺序队列在单位边界切换。

## 反压与完成

CRU 入口 ready 低时只反压对应 C2H 源。每项写入最终 CRU 存储后沿原链路回 `valid+src`，发数据核 CCU 计数。CRU 合并完成不是第三类链路完成协议。
