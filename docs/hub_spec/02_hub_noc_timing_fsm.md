# HUB_NOC 时序与实现分解

## H2C 单源

1. MAE_ENG 给道 n 的 L2 `en/addr`；L2 busy 时保持请求。
2. L2 输出连同目的 addr/be/src 进入通用链路块。
3. 分叉点按核掩码建立每目的已取位；某目的 ready 成交即置位，全部目的取走后才接收下一拍。
4. 每段可插寄存器/skid；分叉位置、级数和回程级数由后端参数决定。

H2C 没有 MAE_CRU 第二源，也没有源顺序队列或单位末拍切换。

## C2H 直通

每核集成输出端口只有一路进入 C2H，C2H 直通 L2WP 第 n 条。ready 低沿链路回传，CCU 对该 ready 做门控并暂停计算；HUB 不缓存、不扇入、不仲裁。

## 写入握手

L2 或 LDP 把一项写进最终 bank 后回 `valid+src`。H2C 回程最多每道四项/拍，按 `src` 汇总或原样转交均可，但不得丢失、重复或错归属。C2H 回程交本核 CCU。

## 命令网

64-bit 握手消息透明转发。标量已改走数据协议（C2H→L2→MAE_CRU），命令网只保留指令、事件、完成和错误消息。

## 参数

各段流水级数、skid 深度、分叉位置、回程级数、L2 busy 门限和 C2H ready 传播深度均为参数或后端约束，不得引入旧 RTT/VC credit/固定地址游标。
