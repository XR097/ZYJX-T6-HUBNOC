# HUB NoC 时序与实现分解

HUB 不再使用旧版“读→等信用→发→等返还”的串行 FSM。实现由可插级通用链路块、分叉状态位和单位边界控制组成。

## H2C 道

1. MAE_ENG 给道 n 的 L2 `en/addr`；L2 busy 时保持请求。
2. L2 数据与目的 `addr/be/src` 进入道首级 MUX。
3. MUX 按 MAE 给的源顺序队列选择 L2 或 MAE_CRU；当前单位最后一拍后才能切源。
4. 分叉点为一级通用链路块加每目的核 1 位已取标志。掩码内某核 ready 即成交并置位；全部置位后才接收上游下一拍。
5. 每段可插寄存器/skid；分叉位置和级数由 backend 参数决定。

## C2H 分流

本核 CCU 在单位边界给出 L2 或 MAE_CRU 选择。每核一路直通，不扇入、不仲裁。下游 ready 直接形成该核链路的反压。

## 写入握手回程

最终存储每写进一项就回 `valid+src`。H2C 回程最多四项/拍，汇总可按 src 聚合或原样转交；不得丢失、重复或错归属。发送方不等待回程才发下一拍。

## 控制道

64-bit `en/ready/data` 消息流，与数据网物理独立；HUB 按类型/源透明转发，不解析业务载荷。控制消息可晚于数据抵达，端点要缓存或拒绝越界操作。

## 参数

`HUB_PIPE_*`（各段级数）、`HUB_FORK_*`（分叉位置/已取位深度）、`HUB_SKID_*`、`HUB_ACK_*`（回程级数）及 L2 busy/将满门限均为 RTL 参数。不得把旧 RTT、VC credit 或固定地址游标写成合同。
