# 设计前门槛速览

完整依据和责任人见[当前问题台账](../reviews/open_issues_current.md)。本页只回答“什么挡住 RTL/验证启动”。

## 必须先关闭

| 范围 | 条目 | 处理 |
|---|---|---|
| 合并启动 | N-18 | 决定定长合并输入是否统一发报告；建议按所有被合并读取的 C2H 写入都报告处理。 |
| 命令网 | N-04 | ISA/LIC/CCU 提供 `addr`、`be`、端点队列深度和复位字段。 |
| L1 / 控制器 | V18-01…V18-08 | 冻结 CONC-6、非对齐访问计数、VNU 流结束、旁带、同拍排序、写让读上界和停止通知。 |

## 只需验证或标定

N-01、N-02、N-05…N-17（不含 N-04、N-18）以及 V18-13…V18-17，按[验证计划](06_verification_plan.md)建立用例；结果回填台账。正文没有规定的输入只做断言，不新增硬件错误状态。

## 已关闭

N-03（`seg` 统一 5 bit）、N-12（旧基线清理）、N-19（按写入拍计数）、N-20（旧路径残句清理）。

设计者必须以 `docs/specs/` 正式篇为准；本目录不另定端口、带宽、握手或所有权。
