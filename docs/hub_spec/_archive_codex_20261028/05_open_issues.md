# 未决项台账

未决项不得在 RTL 中直接写死。每项必须先确定语义接口，再用参数、配置字段或验证假设承载；状态变为“已定”后才允许移除占位。

标签约定：`待审查`=需要架构/协议裁定，`待仿真`=需要周期级模型或回归数据，`待标定`=需要精度、面积或时延测量，`可参数化`=接口已明确但数值保持可配置。
