# HUB_NOC、HUB_IDN 与 MAE_CRU 验证计划

> 适用版本：2026-11-08。验证目标是现行地址+ready+写入握手协议；旧 RHUB 的 VC/credit、H2C 两源 MUX、C2H→CRU 和 BF16-only 用例不再执行。

## 1 接口与结构

- 从正文生成端口矩阵，检查 `din` 32 B、`be`、24 bit `addr`、`seg`、`src`、`vld/en`、ready 和反向写入握手的方向、宽度及旁带同拍关系。
- 检查 HUB_NOC：H2C 道 n 只连接 L2 象限 n；C2H 核 n 只连接 L2WP 象限 n；H2C 每道只有 L2 源，C2H 每核只有集成输出端口来源。
- 检查 HUB_IDN：一路 32 B 输入、四核各一路 32 B 输出；每个存储字的 4 bit 核集合与数据、地址、`be`、`src` 同级流水到最后分叉点。
- 随机化每段寄存器/skid、分叉位置、回程级数和 FIFO 深度，确认插级只增加延迟，不改变数据或握手归属。

## 2 HUB 多播、反压与完成

- 覆盖掩码为空、单播、双播和四播；每个目的 ready 独立变化。分支按已取位工作，慢目的在容量内不阻塞快目的，分支满后才反压上游。
- H2C、HUB_IDN 的每字 `addr/be/src` 与核集合不串拍；到核链路不携带核集合，回程握手按发令号正确汇总。
- C2H 下游 ready 低时，ready 沿链路回到集成输出端口并门控 CCU；恢复后不丢字、不重放、不提前完成。验证四核互不等待和象限绑定错误的致命检查。
- L2 bank busy、LDP/NWB FIFO 满和链路插级只产生停顿计数，不产生协议致命错误；最终写入握手只能在数据真正落 bank 后产生。
- 验证发令方按 `src` 计数：H2C/HUB_IDN 多播应写量 = 存储字数 × 目的核数；C2H 由本核 CCU 计本链路握手。

## 3 MAE_CRU 数据与状态机

- **报告触发**：各核先 C2H 写 L2，只有参与核发出报告全部到齐后才启动对应合并；报告乱序、重复、缺失和不同地址并行均覆盖。`MAE_CRU` 不以入口 FIFO 或按地址到达份数启动。
- **四象限读**：NI 读口按同址读出 4 × 32 B；参与掩码外不等待，掩码内任一象限 bank busy 或跨拍返回时，`ALIGN` 保持到齐后再计算，结果不依赖返回先后。
- **运算参考模型**：逐元素相加、标量求和/最大/对合并、读集按位取并；加法次序按象限固定。输入 FP16、BF16、MXFP6 g32、FP8，输出 BF16、FP16、MXFP6 稠密和按 keep 列表压缩均做 bit-exact 对拍。
- **残差两指令**：第一条归约写 BF16 L2，第二条读归约结果与残差流、一次编码写回；验证 LIC 依赖、失败恢复和 Fusion 分块循环，确保第二条不会早于第一条。
- **写回与完成**：NI-L2C ready 随机拉低，检查保持当前拍；每项 L2 写入握手带正确 `src`，计满应写量后只通知 LIC 一次。发送完成和执行完成不能混淆。

## 4 变长对象与跨模块依赖

- 生产方将 token 按实际长度紧挨写入，长度表独立写入；验证 24 bit 表项（16 bit 字节数 + 8 bit `tokmax`）地址、字节数和跨字对齐。
- MAE 先搬长度表再搬对象，读表项之和决定数据量；搬完后以实际发出项数转发应写量。覆盖长度表先到/后到、对象先到/后到、长度为零、满窗口和超窗口错误。
- 验证压缩输出的 keep 位图/序号列表由 MAE_ENG 读入并交给 CRU，CRU 不读取或回填长度表；L1/L2 完成跨字节对齐和 bank 落位，HUB/MAE 不做字节移位。

## 5 错误、复位和性能

- 地址越界、段/象限选择错误、空掩码（不允许时）、非法编码组合、列表与记录数不匹配应报致命错误并带指令标号；ready 低、bank busy、长度转发晚到不报错。
- 复位发生在报告等待、读返回、合并和写回各阶段时，清除暂存且不产生虚假握手/完成通知；复位后首条指令重新装载参数。
- 统计每条 H2C、HUB_IDN、C2H 和 NI-L2C 的 ready 低拍、bank busy、分支等待、写入握手和实际吞吐；记录 simulator、seed、参数集、参考模型版本和结果。

## 6 退出条件

RTL 开始前关闭接口合同中的 `addr/seg` 语义、C2H ready 门控和命令网消息格式（N-02、N-03、N-04）。以下项目至少有参数化周期模型和回归结果：HUB 级数/分叉/回程（N-01）、`src` 宽度与无 ready 回程（N-08）、HUB_IDN 旁带流水（N-13）、IDN 32 B 吞吐边界（N-14）、MAE_CRU 对齐/编码/压缩（N-05、N-06、N-15、N-17）、归约→残差依赖（N-11、N-16）和紧挨对象长度协议（N-09）。
